# Varchandise

**Varchandise** is an innovative online shopping platform dedicated to action figures, crafted using a combination of powerful frameworks and languages, including **Flutter**, **Node.js**, and **MySQL**. This platform features dual interfaces catering to both users and administrators, ensuring a seamless shopping experience.

## Features

- **User Interface**: 
  - Users can browse and purchase their favorite action figures with ease.
  - Intuitive navigation and search capabilities for a smooth shopping experience.
  
- **Admin Interface**: 
  - Administrators can efficiently manage products, inventory, and user orders.
  - Robust dashboard for monitoring store activities and statistics.

## Technology Stack

- **Flutter**: Used for creating the front-end interface, providing a responsive and engaging user experience.
- **Node.js**: Serves as the backbone for all backend operations, handling requests, authentication, and data management.
- **MySQL**: Integrated as the database to store user data, product information, and transaction records.
